# Contributing to Solina Launcher

Thanks for your interest in improving Solina Launcher.

- Search the [issue tracker](https://github.com/Solina-Projects/Solina-Launcher2/issues) before opening a new issue.
- Keep pull requests focused on one change and describe what you tested.
- Pushes to `main` are built automatically by GitHub Actions; the APKs are attached to each run.
- By contributing you agree that your work is released under the project license (GPL-3.0). See [NOTICE.md](NOTICE.md).
