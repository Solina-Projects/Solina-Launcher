# Contributing to Solina Launcher

Thank you for your interest in contributing to Solina Launcher.

## Before opening an issue

- Search the repository's open and closed issues for an existing report.
- When reporting a bug, include the app version, steps to reproduce, and relevant logs with personal information removed.
- Test builds are available from [GitHub Actions](https://github.com/Solina-Projects/Solina-Launcher/actions). They may contain bugs and are not stable releases.

## Code contributions

1. Work on a dedicated branch; do not commit directly to `main`.
2. Keep changes focused and explain the reason for each change in the commit message.
3. Run the relevant build and tests before submitting a pull request.
4. Do not include credentials, tokens, personal data, or private URLs in commits.
5. Preserve upstream copyright notices and applicable open-source license terms when modifying derived code.

Solina-specific documentation, support channels, and website links will be added here when they are configured.
