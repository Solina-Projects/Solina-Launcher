# Solina Launcher

Solina Launcher is an open-source Android home screen built on Launcher3 and the Lawnchair 16 codebase.

## Current focus

- Home screen customization
- App and web search
- Backup and restore
- Solina branding and a reproducible test-APK build

## Test builds

Test APKs are built by GitHub Actions for development branches and pull requests. They are development artifacts, not stable releases.

[View build workflow](https://github.com/Solina-Projects/Solina-Launcher/actions)

## Project status

This project is under active setup. Official website, support channels, social accounts, and store listings have not been configured yet; no external links are listed until official Solina destinations are available.
