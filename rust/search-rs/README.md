## Batch

`FuzzyScoreIndex` (in `src/port.rs`) pre-processes the choice list once
(`new`) and scores every choice against one query (`run`), on all cores.
The generated JNI batch is `app.lawnchair.search.algorithms.FuzzyScoreBatch`.
